1. {{step}}

2. Handoff — файл `{{handoff}}`. Это снимок «где мы сейчас», а не журнал: перепиши файл целиком (если он есть — сначала прочитай). Каждый пункт старого текста проверь:
   - открытая задача, нерешённый вопрос, договорённость с пользователем, ещё нужная — оставь, сократив до сути;
   - сделанное, список коммитов, хронология «потом… затем…» — удали: история есть в git и в заметках сессий;
   - как устроен модуль, грабли, инциденты, решения «почему X» — это устойчивое знание: перенеси записью памяти (шаг 3) и удали отсюда. Если это правило для CLAUDE.md — оставь в «Помнить» с пометкой «предложить в CLAUDE.md»;
   - пункт, который уже неактуален или сам помечен «неактуально», — удали;
   - CLAUDE.md проекта и память новая сессия получает сама: что там уже есть (правила, грабли, команды запуска и проверок), в handoff не повторяй — ни в «Помнить», ни в «Dev».

   Объём — до ~12 тысяч символов, один пункт — не длиннее абзаца. Формат:

```
# Handoff — <проект> ({{date}})

## Следующая сессия — <тема>
<где остановились: ветка, что сделано в этой сессии, что не закоммичено, что проверено и что нет>

## Дальше
<шаги по порядку, с файлами и командами; первый — конкретный>

## Открытые вопросы
<что ждёт решения пользователя или проверки; нечего — раздел не пиши>

## Помнить
<грабли и решения этой работы, которых нет в CLAUDE.md и памяти; нечего — раздел не пиши>

## Dev
<запуск и проверки, которых нет в CLAUDE.md (временный порт, особый сценарий); нечего — раздел не пиши>
```

3. Итог сессии echo-memory — по инструкции `{{summary}}`. В «Дальше» заметки — ссылка на handoff и первый шаг.

4. Промпт для новой сессии, 1–3 предложения: «Продолжаем <проект> ({{root}}). Прочитай <путь к handoff> — раздел «Следующая сессия — <тема>» — и CLAUDE.md проекта. <первый шаг>.» Запиши его одной строкой без Markdown инструментом Write в файл `{{prompt_file}}` — плагин положит его в буфер обмена.
