# Язык интерфейса Echo Studio — русский

Решение владельца 2026-10-27: весь интерфейс на русском. Новые тексты — сразу по этим правилам.

## Не переводим

- Названия и термины Claude Code — как в Claude Code: Claude, Claude Code, skills, plugins, MCP, agents, hooks,
  commands, statusLine, `/clear`, `/rename` и прочие слэш-команды, auto memory, `CLAUDE.md`, `settings.json`.
  Во множественном числе в русской фразе: «12 skills», «plugins проекта» — без склонения латиницы.
- dev, git, commit, PID, CPU, RAM, JSON, YAML, frontmatter, Markdown, API, URL.
- Имена файлов, папок, ключей конфига, ID, пути, команды терминала.
- Названия программ: Windows Terminal, Git Bash, Zed, VS Code, Chrome, Проводник (так в русской Windows).
- Клавиши: Ctrl, Shift, Alt, Enter, Esc, Tab.

## Правила

1. **Не длиннее английского.** Кнопка, вкладка, заголовок, чип, пункт меню, подпись поля — русский текст по числу
   символов не длиннее английского. Не влезает — ищи короче («Удалить» вместо «Удалить сессию», если рядом и так
   видно, что удаляется), меняй формулировку. Длиннее можно только в предложениях на просторном месте (пустое
   состояние, описание в диалоге) — и такие места перечисли в отчёте.
2. **Понятно и по делу.** Переводи смысл, а не слова. Можно перефразировать, если так яснее. Без канцелярита
   («осуществить», «данный», «в случае если»), без «Пожалуйста».
3. **Без очевидного.** Подсказка, повторяющая кнопку или заголовок, — убрать, а не переводить.
4. **Регистр**: как в предложении — заглавная только первая буква («Открыть в Claude», не «Открыть В Claude»).
5. **Числа**: склонение по числу через `plural` из `src/lib/dashboard.ts` («1 сессия / 2 сессии / 5 сессий»), никаких
   «сессия(и)». Даты и время — `ru-RU`.
6. **Ошибки** говорят, что случилось и что делать: «Файл занят другой программой — закройте её и повторите».
7. Обращение — безлично, где можно («Проект не выбран»); где нужен призыв — на «вы» («Выберите проект»), не на «ты».
