## Процесс

Как в Booked: по одному компоненту → части → стенд вариантов в Artifact → выбор пользователя →
переделка → dev → пользователь смотрит сам. Доработки по замечаниям к текущему шагу — без стенда.
Команда — `/redesign-stand`. Сборка стенда — `node .claude/local/redesign/build-stand.cjs <template>`
(Kockers Sans из `C:/Users/stillmvd/Fonts`, картинки `__IMG_<файл>__` из папки стенда). Сборка компонента видна только в киоске: ссылка стенда + `#kiosk` на втором мониторе повторяет выбор и тему (BroadcastChannel + `storage`), на основной странице — только части (решение пользователя 2026-09-25). Состояния компонента (загрузка, пусто, нет выбора) тоже видны в киоске: сегмент «Состояние» над сборкой, смена варианта в части, которая определяет состояние, переключает на него сама (с шага 3, образец `003-session-table/gen3.cjs`).
