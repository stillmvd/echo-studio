# Стенды фичи 004-memory — раздел памяти

Начат 2026-09-29. Спека, план и задачи — `specs/004-memory/`.

## Правило

Как в `.planning/TOOLING-STANDS.md`: стенд на новый компонент, без блока «Сейчас», части с вариантами + киоск
(`<ссылка>#kiosk`) со сборкой выбранного и сегментом «Состояние». Стиль — после редизайна (Trail), вариантов
ошибок нет. Данные — настоящие с этой машины; поля, которых на диске пока нет (`kind`, `status`, заметки сессий),
проставлены для примера и помечены на стенде. Порядок: стенд → «Выбор: …» пользователя → запись сюда →
реализация → проверка пользователем → коммит.

Папки — `.planning/sketches/2NN-memory-<компонент>/`, генератор — `gen2NN.cjs` на базе `101-tools-layout/gen101.cjs`.
Сборка — глобальная `/redesign-stand` и `~/.claude/tools/redesign/build-stand.cjs --font kockers --kiosk <адрес>` (паспорт — раздел «Стенды» в CLAUDE.md).
