# Стенды фичи v0.3.0 — обзор инструментов Claude

Начат 2026-09-26. Решения и процесс — `.planning/ROADMAP.md`, раздел «v0.3.0 — обзор инструментов Claude»;
спека и задачи — `specs/001-claude-tooling-view/`.

## Правило

Стенд на каждый новый компонент, как в редизайне (`.planning/REDESIGN-TRAIL.md`), но **без блока «Сейчас»** —
компонента ещё нет. Стенд = части с вариантами + киоск (`<ссылка>#kiosk`) со сборкой выбранного и сегментом
«Состояние». Данные — настоящие с этой машины. Порядок: стенд → «Выбор: …» пользователя → запись сюда →
реализация → проверка пользователем → коммит. Язык Trail и решения шагов 1–6 редизайна не пересматриваются.

Папки стендов — `.planning/sketches/1NN-<компонент>/`, генератор — по образцу `006-dialogs/gen6.cjs`.

## Стенд 4 — переключатель (выбор и реализация 2026-09-26)

- **В строке A, «тумблер всегда».** Тумблер 36×22 справа в каждой строке, где есть `toggle`: включён — дорожка
  акцентом, ручка `accent-ink`; выключен — дорожка `--raised` с кольцом `--line`, ручка `--dim`. Клик по тумблеру
  не выбирает строку.
- **В деталях B, «кнопка».** В шапке деталей капсула 40 со значком питания: «Turn off» (тихая, fg 7 %) у
  включённого, «Turn on» (акцент, текст `accent-ink`, bold 13) у выключенного.
- **Выключенное B, «вся строка тусклая».** Выключенный элемент — вся строка 55 % (как недоступные элементы
  выключенного плагина); чипа «off» нет.
- **Нельзя выключить A, «неактивный тумблер».** У commands, agents и элементов плагина — тумблер на 40 %
  непрозрачности в положении текущего состояния, причина (`toggleHint`) — в подсказке по наведению; в деталях —
  неактивный тумблер с подписью «Can't turn off» и подсказкой.
- **Ошибка записи B, «плашка в деталях».** Тумблер откатывается (оптимистичная мутация уже откатывает), в деталях
  элемента — плашка 16 `danger-soft` с текстом ошибки моно; если ошибка случилась из строки без открытых деталей —
  открыть детали этого элемента, чтобы плашка была видна.
- **Где выключается A, «подпись».** В области проекта рядом с кнопкой в деталях тихо «for this project»
  (запись в `.claude/settings.local.json` или запись проекта в `~/.claude.json`). Выбора «везде» нет.
