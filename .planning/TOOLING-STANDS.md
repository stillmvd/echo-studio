# Стенды фичи v0.3.0 — обзор инструментов Claude

Начат 2026-09-26. Решения и процесс — `.planning/ROADMAP.md`, раздел «v0.3.0 — обзор инструментов Claude»;
спека и задачи — `specs/001-claude-tooling-view/`.

## Правило

Стенд на каждый новый компонент, как в редизайне (`.planning/REDESIGN-TRAIL.md`), но **без блока «Сейчас»** —
компонента ещё нет. Стенд = части с вариантами + киоск (`<ссылка>#kiosk`) со сборкой выбранного и сегментом
«Состояние». Данные — настоящие с этой машины. Порядок: стенд → «Выбор: …» пользователя → запись сюда →
реализация → проверка пользователем → коммит. Язык Trail и решения шагов 1–6 редизайна не пересматриваются.

Папки стендов — `.planning/sketches/1NN-<компонент>/`, генератор — по образцу `006-dialogs/gen6.cjs`.
