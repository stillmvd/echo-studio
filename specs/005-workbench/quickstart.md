## 0. Подготовка

- Dev: закрыть `echo-studio.exe`, `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS="--remote-debugging-port=9222" pnpm tauri dev`
  (порты делит с Booked — см. CLAUDE.md).
- Мост лимитов в `~/.claude/statusline.sh` на месте: после любого ответа Claude есть
  `%TEMP%/claude-memory/rate-limits.json`.
- Пробные сессии — в проекте `Echo Studio`; после проверки `claude stop` + `claude rm` (транскрипты остаются, их видно в
  Conversations).

## 3. US2 — статусы и переход

Три сессии в разных проектах; в одной попросить Claude задать вопрос (AskUserQuestion) → ≤ 2 с «ждёт тебя» первой в
«Запущено», в полосе и на строке проекта; свёрнутая группа показывает чип. Ctrl+Tab — список, недавние первыми,
Shift+Tab назад, отпуск Ctrl — переход. Сессия из WT (`cc`) — в «Запущено» с пометкой «вне оболочки», без терминала.

## 4. US3 — dev

AM 2.0 → dev: ≤ 10 с порт веба в капсуле; «открыть» — браузер по умолчанию; лог во вкладке рядом с Claude. Закрыть Echo
→ сервер жив (порт слушает); открыть → капсула «работает». «Стоп» → в диспетчере нет vite и обоих `node --watch`, порт
свободен. Занять порт заранее → капсула «ошибка», лог с причиной. Проект без `dev`/`start` — кнопки нет.

## 5. US4 — пульт

2×2, пять сессий в пяти проектах; одна → «ждёт тебя»: занимает ячейку самой низкоприоритетной незакреплённой, рамка
акцента; вытесненная — в «Вне сетки». Печатать в ячейке во время смены статуса — ячейка не сдвигается, счётчик «ещё
ждут: 1». Булавка держит ячейку. 2×1 ↔ 2×2 — без перезапуска сессий; перезапуск Echo — раскладка та же.

## 6. US5 — продолжить разговор

Booked без сессий → список разговоров, последние сверху, строки различаются временем и первой строкой ответа. Клик →
сессия с этим разговором; клик по разговору, уже открытому в живой сессии, → переход к ней.

## 7. US6–US7 — обзор и процессы

Плитки лимитов совпадают со статусной строкой Claude; удалить `rate-limits.json` → «нет данных». Токены за 7 дней по
проекту совпадают с `node .planning/sketches/301-workbench/usage.cjs`. Git-счётчики совпадают с `git status`.
Закрыть WT-сессию с chrome-devtools MCP → его node и Chrome-профиль — в «Без проекта» с причиной; «Завершить все» убирает
только их. «Завершить» у живой сессии — диалог подтверждения. Личный Chrome в списке отсутствует. Доля
классифицированных процессов ≥ 95% (SC-005).

## 8. Проверки

`pnpm biome check .` → `pnpm typecheck` → `pnpm test` → `pnpm build`; `cargo clippy --all-targets -- -D warnings`,
`cargo test`. Юнит-тесты: дерево (правила sync-workspace), `desktop.ini` UTF-16LE, dev-команда, разбор `git status`,
слияние `agents --json` + хук, классификация процессов, `arrangeCells`, клавиши терминала.
