# Quickstart: проверка доработок v0.3.1

## Подготовка

- `pnpm tauri dev` (для CDP: `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS="--remote-debugging-port=9222"`).
- Машина с установленными skills (`gsd-*`, `speckit-*`), плагином chisle и проектами без папки.

## Сценарии

1. **Отступы результата (US5)**: Conversations → любая сессия с Bash/Read. Превью в 1 и 2 строки — отступ
   снизу равен верхнему; длинный результат свёрнут до 2 строк с теми же отступами.
2. **Карточка вопроса (US4)**: сессия, где задавались вопросы с вариантами. Видны все вопросы, выбор
   отмечен; свой ответ — текстом; multiSelect — несколько отметок; отклонённый вопрос — «No answer».
   Экспорт сессии в markdown содержит «вопрос → ответ».
3. **Группы skills (US1)**: Tools → Global → Skills. Группы «gsd», «speckit», «chisle» свёрнуты по
   умолчанию (или как выбрано на стенде) с верными числами; `better-ui` без группы. Раскрыть «gsd»,
   перезапустить приложение — группа раскрыта. Поиск «milestone» показывает совпадения внутри группы.
4. **Дубликаты (US2)**: создать `~/.claude/skills/chisle/SKILL.md` (имя как у skill плагина chisle). Оба
   помечены «same name», в шапке «N duplicates»; клик — остаются только дубликаты; повторный — полный список.
   Удалить тестовый skill.
5. **Missing-проекты (US3)**: панель All scopes — живые проекты выше, внизу свёрнутая «Missing · N».
   Раскрыть, выбрать проект — путь, число сессий, «Open in Conversations» открывает его сессии. Проект без
   сессий — «No sessions». Файлы конфигурации не изменились (`git status` в `~/.claude` не нужен — сверить
   дату изменения `~/.claude.json`).

## Автопроверки

`pnpm biome check src` → `pnpm typecheck` → `pnpm test` → `pnpm build`; `cargo clippy --all-targets -- -D warnings`,
`cargo test`.
