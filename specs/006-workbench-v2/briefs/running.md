## Детали

- T051 «Запущено»: группы по проекту (порядок — по срочности самого срочного внутри, `byUrgency`), строка проекта —
  `ProjectIcon` + имя + общий статус (самый срочный) жирным белым; под ней серыми строками сессии (имя сессии,
  статус) и dev (команда, порт). Клик по проекту — открыть проект (как клик в дереве), по сессии/dev — открыть эту
  вкладку (существующие `goSession`/`openDev`). Корень `Projects` — группа «Projects» (внешние сессии вне проектов
  — туда же, с подсказкой). Меню ПКМ (`runningMenu`, `runningDevMenu` из пачки 3) — на строках сессий/dev; на строке
  проекта — `projectMenu`. Строки кликаются целиком, без смены размера, без выделения текста.
- T052: чипы активности (`ProjectChips` в дереве) убрать; дерево — только навигация (иконка, имя, счётчик групп).
- T053: нижняя полоса — две отдельные пилюли. Слева «Недавние»: последние 5–6 сессий, которые пользователь
  открывал (история переходов, новый persist-стор `recent-store.ts`: `visit(sessionId)` при активации вкладки
  сессии, без дублей, завершённые и удалённые выпадают). Ctrl+Tab (`QuickSwitch`) ходит по той же истории. Групп
  «Вне сетки» и полного списка нет. Справа — короткая отдельная пилюля watching (как была плавающая до 006: то же
  содержимое и подсказка), точку `.wb-watch` убрать.
- T054 статусы: подписи и `title`-подсказки у значка и строки для всех статусов. По умолчанию: работает — «Claude
  отвечает»; ждёт тебя — «Claude задал вопрос или ждёт подтверждения»; ответ готов — «Claude закончил, ответ ещё не
  открывали» (после просмотра `effectiveStatus` → ждёт задачу); ждёт задачу — «Можно писать следующую задачу»; новая
  · ждёт задачу — сессия без первого запроса (вместо «паузы» `||`); ошибка; завершена; вне Echo — «Открыта в
  терминале вне Echo». Как узнать «без первого запроса» — посмотри поля `ClaudeSession` (`src/lib/types.ts`) и что
  отдаёт Rust (`sessions::list`, файл хука `task`, `first_prompt`); не хватает данных из Rust — напиши координатору,
  что нужно (поле, источник), он сделает Rust сам. Тесты на подписи/`effectiveStatus`.
- T058 (после выбора стенда): `StatusIcon` — один размер, заполненный круг, белый глиф, цвет по типу; dev-точка —
  в том же стиле. Детали придут с номером варианта.
