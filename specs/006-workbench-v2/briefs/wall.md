## Детали

- Модель — `data-model.md` «WorkbenchState v3» и research R-05. Главный инвариант: `tabs[path]` — источник истины об
  открытых вкладках; `projectLayouts[path]` только распределяет их по ячейкам. `normalizeLayout` вызывается в
  селекторе/геттере, чтобы устаревшие раскладки не ломали рендер.
- В режиме «Проект» существующая `Cell` получает `keys` (вкладки ячейки) вместо чтения всего `tabs[path]`; терминалы
  вкладок других ячеек того же проекта — свои экземпляры (как сейчас в пульте — `controlled`). Один `ConfirmDialog`
  завершения — на ячейку, как сейчас.
- Пустая ячейка в режиме «Проект» (когда у проекта раскладка 2×1 и во второй ячейке нет вкладок): «Свободная ячейка»,
  кнопки «+ Claude» (`onStart` → новая сессия, вкладка — в эту ячейку: сделай `focusProjectCell` перед `start`) и
  капсула dev, подсказка «Перетащите сюда вкладку». `EmptyProject` (список «Продолжить») — только когда у проекта нет
  ни одной вкладки, в фокусной ячейке 1×1 (как сейчас).
- `ModeSwitch` — сегмент в стиле `.wl-seg` (F2 уже сделал сегмент раскладки — переиспользуй класс). Ставится в шапку
  правой карточки: в режиме «Проект» — в `ProjectHeader` слева от `LayoutPicker` (проп `extra` уже есть), в
  «Пульте» — в `wl-tb`. Подсказки из tasks T031.
- `LayoutPicker` в режиме «Проект» управляет `projectLayouts[path].layout` (проп `value`/`onChange` вместо чтения
  глобального `layout` из стора); в пульте — как раньше.
- DnD (R-04): `useTabDrag`/`useTabDrop` в `useTabDrag.ts`. Тип данных `text/x-echo-tab`. Подсветка `.wl-cell.drop`,
  указатель `.wb-tab-ins`. В пульте сброс в ячейку другого проекта: ячейка → проект вкладки, `manual: true`,
  `activeTab` = вкладка; в режиме «Проект» — `moveTab`. Нельзя сбросить вкладку в чужой проект в режиме «Проект»
  (все ячейки одного проекта — вопрос не стоит).
- Закрытие последней вкладки ячейки — ячейка пустеет (не схлопывается раскладка).
- Ctrl+Tab / «Запущено» / полоса в режиме «Проект»: переход к сессии — `select(project)` + активировать вкладку в её
  ячейке (`cellOfTab`), фокус терминала.
- Миграция v3 — тест: состояние v2 с `tabs`/`activeTab` → `projectLayouts` с одной ячейкой; `mode: 'project'`;
  пульт не теряет `cells`.
- `desktop-app-peeves`: кнопки не меняют размер при смене подписи; без тостов; курсор `grab` на перетаскиваемой
  капсуле; никаких анимаций ширины.
