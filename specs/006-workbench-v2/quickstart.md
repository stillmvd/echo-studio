# Quickstart: проверка Рабочего места v2

Контракт — [contracts/ipc.md](contracts/ipc.md), модель — [data-model.md](data-model.md), решения —
[research.md](research.md). Ограничения живых проверок — `.planning/ORCHESTRATION-006.md`, раздел «Нельзя трогать»:
только Echo Studio, Breeze, Booked, Tolk; чужие сессии и dev не трогать.

## 0. Подготовка

- Dev из worktree на свободных портах (1420/9222 заняты пользователем): `pnpm tauri dev --config <json>` с
  `{"identifier":"com.stillmvd.echo-studio.check","build":{"devUrl":"http://localhost:1425","beforeDevCommand":"pnpm dev
  --port 1425 --strictPort"}}`, `ECHO_BACKGROUND_DEV=1` и `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS="--remote-debugging-port=9226
  --disable-features=CalculateNativeWinOcclusion --disable-backgrounding-occluded-windows"`. Свой identifier — своё
  состояние окна и профиль WebView2 (не трогают Echo пользователя); `ECHO_BACKGROUND_DEV` (только debug) — без заставки,
  окно за пределами экрана, без кнопки на панели задач и без фокуса; без флагов occlusion WebView2 за экраном не рисует.
  Управление — CDP 9226; закрыть сразу после проверки (`WM_CLOSE` окну), не держать открытым между шагами.
- Пробные сессии — в Echo Studio или Tolk; после проверки `claude stop` + `claude rm`.
- MCP-браузер закрыть после проверки.

## 1. Внешняя сессия (US1)

1. Открыть `claude` в Windows Terminal в папке Tolk (пункт проводника «Открыть с Claude»).
2. В Echo «Запущено»: строка «вне оболочки» активна (не серая). Клик → окно WT вперёд (в т. ч. свёрнутое). То же из
   полосы.
3. Закрыть вкладку WT → строка остаётся как «завершена · вне оболочки»; клик → «Продолжить в Echo» → вкладка с этим
   разговором в оболочке.
4. Сессия пользователя в корне `Projects` (`projects-19`): клик выводит её окно; «Продолжить в Echo» не предлагается.

## 2. Дерево (US2)

- `ProHouse\Smart Control-review` отсутствует в дереве. ПКМ по `Breeze` → «Скрыть из дерева» → пропал; Settings →
  Рабочее место → «Вернуть» → вернулся.

## 3. Отключение (US3)

1. Пробная сессия в Echo Studio, `/exit` → ≤ 1 с ячейка показывает «Отключено от сессии»; «Вернуться» → снова TUI той
   же сессии. Повторить для Ctrl+Z и двойной «←» на пустом поле.
2. Во время ответа Claude — Ctrl+C прерывает ответ, подключение живо.
3. Крестик вкладки: подсказка «Скрыть вкладку — сессия продолжит работать»; сессия в «Запущено» осталась.
4. «Завершить сессию» в шапке ячейки → подтверждение → сессии нет в «Запущено».

## 4. Элементы управления (US4)

- Скриншот шапки проекта с работающим dev (Echo Studio на 1425): «Стоп» — заполненный красный квадрат, подсказка
  «Остановить dev-сервер»; сегмент раскладки с разделителями отделён от капсулы; чип MCP — значок Chrome.
- Нижняя полоса: справа индикатор слежения с подсказкой; плавающей таблетки нет ни в одном разделе.

## 5. Процессы (US5)

- Обзор → Процессы: группа «Projects (корень)» с сессией пользователя и её MCP; в «Echo Studio» каждая фоновая сессия —
  строка сессии с её процессами; «Без проекта» — пусто или с подсказкой у заголовка.

## 6. Пустой проект (US6)

- Открыть Booked (без сессий): на месте списка силуэты, затем список; кнопки не сдвинулись (сравнить два скриншота
  по координатам кнопок).

## 7. DnD и режимы (US7, US8)

1. Режим «Проект», Echo Studio, раскладка 2×1: вкладки «Claude» и «dev» в первой ячейке → перетащить «dev» во вторую
   (ячейка подсвечена) → dev справа; оба работают. Перетащить обратно перед «Claude» → порядок изменился.
2. Переключить на Tolk (1×1), обратно на Echo Studio → 2×1 с теми же ячейками. Перезапуск Echo → всё на месте.
3. «Пульт» → общая сетка, авто-порядок, булавки, «Вне сетки» работают; «Проект» → раскладки проектов целы.
4. Меню вкладки → «Переместить в ячейку…» → ячейка 2 → перенесена.

## 8. Меню (US9)

- ПКМ по проекту, вкладке сессии, вкладке dev, строке процесса, строке «Запущено»: меню от точки клика с анимацией,
  стрелки/Enter/Esc, клик мимо закрывает; у правого края окна меню внутри окна. «Копировать путь» → буфер содержит путь.

## 9. Проверки

`pnpm biome check .` → `pnpm typecheck` → `pnpm test` → `pnpm build`; `cargo clippy --manifest-path src-tauri/Cargo.toml
--all-targets -- -D warnings` → `cargo test --manifest-path src-tauri/Cargo.toml`.
