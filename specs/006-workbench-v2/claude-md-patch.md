## «Ключевые инварианты» — дополнение к пункту «Рабочее место»

```
  Внешние сессии (интерактивный `claude` в терминале) — из файлов хука `~/.claude/state/sessions`: клик выводит окно
  консоли по `claudePid`, только если этот pid сейчас живой `claude.exe` (pid переиспользуются); завершённая внешняя
  в известном проекте — «Продолжить в Echo» (`claude --bg --resume <id>`). Папка с `.git`-файлом (git worktree) — не
  проект и не группа дерева. `claude agents --json` — через кэш 3 с (`run_agents_cached`), хаб сессий не чаще раза в
  3 с; `stop`/`rm`/`--bg` сбрасывают кэш. Отключение от сессии (agent view, вопрос доверия к `~`, выход attach) —
  детектор по коротким префиксам строк в хвосте буфера xterm → состояние «Отключено»; «Завершить сессию» —
  `claude stop` с подтверждением, крестик вкладки только скрывает вкладку.
  Режимы: «Проект» — у каждого проекта своя раскладка и ячейки (`projectLayouts`), «Пульт» — общая сетка 005; у режимов
  свой порядок вкладок. DnD вкладок — HTML5, у окна `dragDropEnabled: false` (иначе Tauri забирает drop себе).
  Контекстное меню одно на приложение (`ContextMenu.tsx`, портал в body, хост в `WorkbenchLayout`), стиль Kockers
  `t-menu`; ПКМ по xterm и полям ввода не перехватывается.
```
